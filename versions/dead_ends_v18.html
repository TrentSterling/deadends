Connection help

For sharing, put this file on an HTTPS site such as GitHub Pages. Hosting serves the page; the host player's browser runs the game. PeerJS handles discovery and WebRTC carries gameplay.

A local file can work online, but browser and network restrictions vary. Online room ready means discovery connected, not that every friend's network can reach the host. For an offline two-tab test, serve this file on localhost and use the same browser profile.

This prototype uses public PeerJS services. There is no public server list, dedicated game server, or host migration. Keep the host tab open and active.
